# OpenWire RU ReadMe

### [EN ReadMe](README.md)

> Нативный Linux-саундпад и realtime-процессор эффектов для PipeWire.

> **Примечание о дизайне:** визуальная концепция и часть дизайн-решений интерфейса были созданы с помощью ИИ и затем адаптированы под проект.

OpenWire помогает быстро запускать звуковые эффекты, обрабатывать микрофон и
выводить обработанный сигнал в виртуальный микрофон. Проект рассчитан на
стримы, голосовые чаты, игры и другие сценарии, где важны быстрый отклик и
управление с клавиатуры.

## Возможности

### Звуковая доска

- динамическое добавление падов без фиксированного лимита;
- воспроизведение MP3, WAV, FLAC, OGG, AAC и M4A;
- режимы `one-shot`, `loop` и `toggle`;
- отдельная громкость мониторинга и виртуального микрофона;
- waveform-просмотр и настройка начала/конца фрагмента;
- басовый boost и быстрый stop всех звуков.

### Обработка микрофона

- pitch и formant shift;
- четырёхполосный эквалайзер;
- radio FX: band-pass, saturation и noise bed;
- мягкое шумоподавление с регулируемым порогом;
- ducking микрофона во время воспроизведения падов;
- пресет **«Обычный голос»** для возврата к нейтральному звучанию;
- отдельный переключатель **«Слышать себя»**.

### Управление приложением

- глобальные горячие клавиши;
- работа в фоне через системный трей;
- открытие, скрытие и закрытие окна из меню трея;
- виртуальный микрофон PipeWire;
- тёмный интерфейс;
- низколатентный аудиограф.

## Как это работает

```text
Физический микрофон
        │
        ▼
  PipeWire capture
        │
        ▼
   DSP-цепочка ───────────────► Виртуальный микрофон OpenWire
        │
        └─────────────────────► Локальный мониторинг

Пады ─────────────────────────► Виртуальный микрофон + мониторинг
```

Frontend отвечает за интерфейс, настройки и управление падом. Rust-бэкенд
отвечает за PipeWire, DSP, декодирование файлов, горячие клавиши и сохранение
пресетов.

## Требования

- Linux;
- PipeWire и доступ к аудиоустройствам;
- Rust 1.77 или новее;
- Cargo;
- Node.js и npm;
- системные зависимости Tauri/WebKit.

Поддержка глобальных клавиш зависит от графического сеанса. На X11 они обычно
работают глобально. В Wayland доступность захвата клавиш определяется
compositor’ом и его политикой безопасности.

## Запуск из исходников

```bash
git clone <URL-РЕПОЗИТОРИЯ>
cd OpenWire
npm install
npm run build
cargo run --manifest-path src-tauri/Cargo.toml
```

`npm run build` собирает CSS и копирует JavaScript и шрифты в `ui/`. Каталог
`ui/` используется Tauri как готовая frontend-директория.

Для Arch Linux зависимости сборки можно установить так:

```bash
sudo pacman -S --needed base-devel rust nodejs npm pipewire webkit2gtk-4.1
```

Названия пакетов могут отличаться в других дистрибутивах.

## Сборка Arch Linux-пакета

```bash
cd packaging
./build.sh
```

Готовый файл `openwire-*.pkg.tar.zst` появится в `packaging/`.
Собранные пакеты лучше публиковать в разделе GitHub **Releases**, а не хранить
в истории исходников.

## Использование

### Добавление звука

1. Запустите OpenWire.
2. Выберите банк.
3. Нажмите **«Добавить пад»** или выберите пустой пад.
4. Импортируйте аудиофайл.
5. Настройте громкость, режим воспроизведения, обрезку и горячую клавишу.

### Настройка голоса

1. Откройте раздел DSP.
2. Для возврата к чистому сигналу выберите **«Обычный голос»**.
3. Для шумоподавления включите соответствующую функцию и настройте порог.
4. Если не нужно слышать свой микрофон, отключите **«Слышать себя»**.
5. Сохраните подходящую конфигурацию как пресет.

Пресеты хранятся в формате TOML. Пример находится в
`examples/presets/`.

## Горячие клавиши

Поддерживаются:

- буквы и цифры;
- F1–F12;
- NumPad;
- Space, Tab, Enter, Backspace;
- Insert, Delete, Home, End;
- Page Up, Page Down;
- стрелки, CapsLock, PrintScreen, ScrollLock и Pause.

Горячую клавишу можно назначить в правой панели выбранного пада. Глобальный
обработчик продолжает работать, когда окно скрыто в системный трей.

## Структура проекта

```text
src/
├── css/             исходные стили и дизайн-токены
├── js/              исходный frontend-код
└── fonts/           используемые шрифты

src-tauri/
├── src/             Rust-код и PipeWire-аудиодвижок
├── capabilities/   разрешения Tauri
├── icons/           иконки приложения
└── tauri.conf.json  конфигурация Tauri

ui/                  собранный frontend для Tauri
examples/            примеры пресетов
packaging/           PKGBUILD и скрипт сборки
scripts/             вспомогательные скрипты
tests/              frontend smoke-тесты
```

Генерируемые файлы не редактируются вручную:

```text
ui/app.css
ui/app-icon.svg
ui/fonts/
ui/js/
```

Локальные данные пользователя не следует публиковать:

```text
settings.toml
soundboard.toml
Voices/
```

## Разработка

Проверка frontend:

```bash
npm test
```

Проверка Rust-кода:

```bash
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
```

Перед отправкой изменений рекомендуется выполнить все четыре команды.

## Устранение проблем

### Нет звука

Проверьте, что PipeWire запущен и устройства доступны:

```bash
systemctl --user status pipewire pipewire-pulse
pw-cli info all
```

### Прерывистый звук

- проверьте нагрузку CPU;
- убедитесь, что PipeWire не работает с чрезмерно большим quantum;
- попробуйте временно отключить тяжёлые DSP-эффекты;
- проверьте, что приложение запущено без конкурирующих аудиомаршрутов.

### Не работают глобальные клавиши

На X11 проверьте, что приложение имеет доступ к устройствам ввода. На Wayland
проверьте ограничения compositor’а: глобальный пассивный захват клавиш может
быть запрещён самим графическим сеансом.

### Окно исчезло после закрытия

Это штатное поведение: приложение скрывается в системный трей. Откройте меню
иконки OpenWire на панели и выберите **«Открыть окно»**.
