# OpenWire

Нативный Linux-саундпад и процессор эффектов для PipeWire.

## Предупреждение

Дизайн в проекте был создан с помощью ИИ так как я не дизайнер и ИИ явно сделает дизайн для проекта лучше чем я

## Возможности

- звуковая доска с неограниченным количеством падов;
- глобальные горячие клавиши;
- пресеты голоса, включая встроенный **«Обычный голос»**;
- pitch, formant, EQ, radio FX, ducking;
- мягкое шумоподавление с настраиваемым порогом;
- отдельный переключатель «Слышать себя» для мониторинга в наушниках;
- виртуальный микрофон PipeWire;
- системный трей: при закрытии окно скрывается, а приложение продолжает работать.

## Требования

- Linux;
- PipeWire;
- Rust 1.77+ и Cargo;
- Node.js и npm;
- зависимости Tauri/WebKit для вашего дистрибутива.

Для Arch Linux пакет можно собрать через `packaging/build.sh`.

## Запуск из исходников

```bash
npm install
npm run build
cargo run --manifest-path src-tauri/Cargo.toml
```

## Проверки

```bash
npm test
cargo test --manifest-path src-tauri/Cargo.toml
```

## Сборка пакета Arch Linux

```bash
cd packaging
./build.sh
```

Готовый пакет будет находиться в `packaging/`.

## Структура проекта

```text
src/          исходники интерфейса: JavaScript, CSS, шрифты
src-tauri/    Rust-бэкенд и PipeWire-аудиодвижок
ui/           собранный интерфейс для Tauri
Voices/       пользовательские пресеты .toml
examples/     безопасные примеры пресетов для репозитория
packaging/    Arch Linux PKGBUILD и скрипт сборки
scripts/      вспомогательные скрипты сборки
tests/        smoke-тест интерфейса
```

`ui/js`, `ui/fonts`, `ui/app.css` генерируются из `src/` командой
`npm run build` и не должны редактироваться вручную.

`Voices/`, `settings.toml` и `soundboard.toml` содержат локальные данные и
исключены из Git. Примеры пресетов для публикации находятся в
`examples/presets/`.

## Горячие клавиши

Поддерживаются буквы, цифры, F1–F12, NumPad, стрелки, Insert, Delete,
Home, End, Page Up, Page Down, Enter, Backspace, Tab, Space и другие
стандартные клавиши.

На X11 горячие клавиши работают глобально, в том числе при скрытом окне.
На Wayland возможность глобального захвата клавиш зависит от используемого
композитора и его настроек безопасности.
